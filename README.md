In Zommbie Defense game, the player's mission is to defend the generator that powers the compound's defenses. The player must survive as long as possible, defeat all zombies and move to the next level. Each level brings more zombies, faster and stronger than before.

To play, you press:
w/up arrow to move up
s/down arrow to move down
A/left arrow to move left
D/right arrow to move right
Space for magic attack(damages all zombies in range)
Escape to quit game

To run the project, you must have:
.NET SDK version 9.0 or later
MonoGame version 3.8+
Visual Studio Code 
Git for cloning

then, you:
git clone https://github.com/1kirezi/Arena.git
cd Arena
dotnet restore
dotnet build
dotnet run --project Arena.Game/Arena.Game.csproj

You will see and play the game.
